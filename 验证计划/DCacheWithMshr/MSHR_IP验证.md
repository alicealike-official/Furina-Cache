# MSHR IP验证

版本：v3.0（按验证层级拆分）；更新日期：2026-11-19。

## 1. 范围与使用方法

本文件承接MSA、MSB、MSC三类共48项专属验证点，以及Way Lock模块输出和通用条目中的MSHR部分。
直接驱动alloc、merge、查询、内存读响应、fillReady和replay.ready，检查内存读请求、fill、replay及lockMask。
上游必须遵守合法Entry/Slot、merge状态、CPU ID以及set/way分配的前提。
Way Lock是否真正阻止DCache命中和victim选择、CPU是否被正确反压，归DCache顶层文件。

fillReady反压契约、读请求/响应同拍以及运行中复位仍按相关Q项确认。
MSHR复位要求以自身确认的架构/接口为准，WBB的低有效复位决定不自动更改MSHR契约。

保留原验证点编号、优先级、检查方式和历史状态，新增“本文件检查范围”列限定本层职责。原条目的文字作为追溯基线，遇到后来确认的接口约定时按本文件范围说明执行。

共享编号可同时出现在多个文件，分别对应模块与集成责任。执行记录使用“文件名＋编号”标识，某一层通过后仍需分别完成其他层的检查。P0为功能/协议必测，P1为重要边界与配置，P2为扩展性能统计。

相关文件：[WBB_IP验证.md](WBB_IP验证.md)、[DCache顶层验证.md](DCache顶层验证.md)。
